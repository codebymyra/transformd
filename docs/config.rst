The Configuration File
======================

To be used in conjunction with isEE_framework. 

Settings: 

``md_engine``
    A string representing the desired MD engine. E.g. amber

``working_directory``
    Directory generated by isEE where the result trajectories live.

``feature_data_directory``
    A directory where the extracted feature files will be saved. A new directory will be created if it does not already exist. 

``log_directory``
    A directory where a log of the processed trajectories will be saved. 
    A new directory will be created if it does not already exist. 
    A file will be saved there called ``trajectory_log.pkl``

``md_data_directory``
    A directory where a history of all the sequences and corresponding feature arrays will be saved. 
    A new directory will be created if it does not already exist.
    The file saved will be called ``raw_data.pkl``
